# redb-tsak-worker:4.2.0. A module dependency present here is NOT packed into the .tpkg; every other
# dependency travels inside the package.
#
# The worker resolves these from its own folder and from Libs/shared next to the application
# (Libs/shared under the app directory, not the current one). A Tsak host built locally from the
# tsak-worker template ships a smaller set: put the assemblies a module needs (redb.Route.File,
# redb.Route.GenericFile, ...) into that host project Libs/shared - the template copies Libs/** to
# the output - or pack them by removing them from this list.
#
# Regenerate when the worker image changes:
#   docker run --rm --entrypoint sh redb-tsak-worker:<version> -c "ls /app/*.dll /app/Libs/shared/*.dll" | sed "s|.*/||" | sort -u
